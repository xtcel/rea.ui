# PLViews 桌面端设计系统

## 方向

PLViews 是只读 PLM 进度视图。界面借鉴 monday.com 的工作区导航、分组表格、列式信息与带文字的状态标签，保留工程项目的证据追溯与诚实判定。monday.com 的 [看板基础](https://support.monday.com/hc/en-us/articles/115005317249-The-basics-of-a-board) 和 [状态列](https://support.monday.com/hc/en-us/articles/360001269685-The-Status-Column) 是结构参考，不复刻其品牌标识。

主稿为浅色；深色令牌包是同一系统的扩展。桌面基准画板 **1440 × 900**，导航宽 **232px**，顶栏高 **64px**。持续使用的区域靠表面色与 1px 边线分隔；只有弹层使用阴影。

## 设计令牌

可导入 ReaUI 的令牌包：

- `plviews-light.system.json`：浅色主稿，已固定到 `.reaui` 文档。
- `plviews-dark.system.json`：深色扩展，保留相同令牌名与组件规则。

基础色：主操作 `#5B55D6`、画布 `#F7F8FB`、表面 `#FFFFFF`、正文 `#253047`、辅助正文 `#59677A`、边线 `#E2E6EE`。状态色每种都有文字与浅色背景：

| 语义 | 文字色 | 规则 |
| --- | --- | --- |
| 已完成 | `#147D60` | 受控文件与前置条件均满足 |
| 已齐套待确认 | `#087477` | 文件齐套，仍需人工确认 |
| 文件不齐 | `#9B6100` | 缺少必需文件项 |
| 待前置 | `#5E6E82` | 上游节点尚未完成 |
| 异常 | `#B83C4C` | 作废或版本冲突等 |
| 数据不足 | `#7751B8` | 不计入可识别节点分母；与未开始分开 |
| 未开始 | `#5D6D82` | 可判定但尚无文件或进展 |

字号以 12px 辅助、14px 正文、28px 页面标题为主，密集表格与节点允许 11/13px，区块标题允许 16–20px。间距使用 8px 基数；控件圆角 8px，面板圆角 12px。ReaUI 当前 ABI 只记录三种排版角色，因此扩展字号会有 `DS_OFF_SCALE` 提示；它们是本稿刻意保留的密度级别。

## 组件与行为

- **工作区外壳**：左侧导航保持稳定；当前页使用浅紫背景和文字，不靠颜色单独表达。任务和甘特图置灰，标记“即将上线”。
- **分组数据表**：40px 表头、约 56px 行；名称左对齐、数值列稳定对齐。默认用文字状态，异常项可见。
- **进度节点**：单项目 DAG 只读，节点显示编号、名称与状态；点击节点展示证据。模板 DAG 可拖拽、连线与编辑规则。
- **证据面板**：展示所需文件、命中文件、缺失项、规则版本和人工修正入口。文件链接仅跳往 PLM。
- **操作顺序**：模板先保存草稿和试算，试算后发布；新项目先确认再绑定模板；已有实例不因新模板发布自动变化。
- **数据诚实性**：项目进度 = 已完成节点数 / 可识别节点数。数据不足单列，异常与数据陈旧不可静默隐藏。
- **文案**：字段用示例占位文字，提交失败时显示错误；正常看板不常驻说明横幅。

设计稿中的项目、用户、文件数量及同步时间均为**示例数据**。页面为可编辑静态设计，不代表已实现交互或接入真实 PLM。
