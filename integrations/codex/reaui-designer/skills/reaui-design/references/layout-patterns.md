# 页面布局骨架

所有坐标以画板左上角为原点。先定结构，再填内容，最后调间距。

## 1. 后台工作台（1440×1024）

```text
┌──────────┬────────────────────────────────────────────┐
│ 侧栏 240 │ 顶栏 64                                    │
│          ├────────────────────────────────────────────┤
│ logo     │ 页面标题 + 说明          [次按钮] [主按钮] │
│ 菜单 ×5  │ 指标卡 ×4（gap 24）                        │
│          │ 趋势图（宽 720）     活动列表（宽 360）     │
└──────────┴────────────────────────────────────────────┘
```

- 侧栏：`absolute left-0 top-0 w-[240px] h-[1024px] bg-[#1f2430]`
- 顶栏：`absolute left-[240px] top-0 w-[1200px] h-[64px] bg-white border-b border-[#e5e7eb]`
- 内容起点：`left-[280px] top-[104px]`，右边距 64px（内容宽 1096）
- 指标卡：4 列，卡宽 250、间距 24、高 120
- 图表卡：`w-[700px] h-[360px]`；活动列表：`w-[372px] h-[360px]`

## 2. 列表页（1280×900）

```text
标题 + 说明                    [导出] [+ 新建]
[搜索 320] [状态筛选 160] [日期 180]        共 128 条
┌────────────────────────────────────────────────────┐
│ 表头 40                                            │
│ 行 52 × 8                                          │
└────────────────────────────────────────────────────┘
                              上一页  1 2 3  下一页
```

- 页面边距 32px。
- 筛选栏高 40，控件间距 12。
- 表格宽 1216，表头 `h-[40px] bg-[#f9fafb]`，行 `h-[52px] border-b border-[#e5e7eb]`。
- 列宽示例：名称 320 / 负责人 160 / 状态 120 / 更新时间 180 / 操作 120。

## 3. 表单 / 设置页（1440×1024）

```text
侧栏 240 │ 内容列 640，左对齐，顶部 96
         │ 分组标题
         │ 字段（标签 12 / 输入 40 / 间距 20）
         │ …
         │ [取消] [保存]
```

- 单列宽度 640，超过 6 个字段才考虑两列。
- 字段间距 20；分组间距 40；分组之间用 `border-b border-[#e5e7eb]`。
- 主按钮右对齐，与最后一个字段间距 32。
- 危险操作单独分组，使用 `text-[#d64545]`。

## 4. 移动端（390×844）

```text
状态栏 44（可省略）
标题 56
内容滚动区
底部 tab 64
```

- 内容左右边距 20px。
- 列表项高 72，头像 40，标题 15px，副标题 13px。
- 底部 tab：`absolute left-0 top-[780px] w-[390px] h-[64px] bg-white border-t border-[#e5e7eb]`。
- 主操作使用底部固定按钮时，高度 48，左右边距 20。

## 5. 通用排版

- 标题与正文间距 8；区块标题与内容间距 16。
- 卡片内：标题 16、说明 13、指标 30，垂直间距 6–12。
- 同一屏内字号不超过 4 档。
- 每个页面只设一个视觉焦点：最大的数字、主图或主按钮。
- 空状态：图标/几何图形 + 一句说明 + 一个主操作。
