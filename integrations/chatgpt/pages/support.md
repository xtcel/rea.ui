# ReaUI Designer support

Contact **xtcel** at [xtcelzhangyong@gmail.com](mailto:xtcelzhangyong@gmail.com)
for help with ReaUI Designer installation, validation, export, and editor
compatibility.

Describe what you were trying to do, your plugin and Node.js versions, and the
error message. Attach a small reproducible example only when needed. Remove
passwords, tokens, personal information, and confidential designs before sending.

Designs run locally. Support cannot inspect your local files unless you choose
to send them. Support email and attachments are used only to handle your request,
are not shared with others, and are deleted within 90 days after the issue is
closed. You can request earlier deletion at the same address.

For a `rea.json` validation error, use the bundled CLI to validate the document
and include its error code. Documents with an embedded v4 design system require
a v4-compatible REA UI editor; REA UI desktop 0.1.0 cannot open them.
