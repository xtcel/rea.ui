## Functionality and requirements

The plugin creates, edits, validates, and exports static UI design documents.
It runs locally and requires Node.js 22.18 or newer. A compatible REA UI editor
is needed to continue visual editing, and documents with embedded v4 systems
need an editor that supports v4.

Review generated content and validation results before relying on a design.
Format validation checks the document contract; it does not establish visual
quality, accessibility, or working application behavior. Keep backups of files
before requesting edits or replacement exports.
