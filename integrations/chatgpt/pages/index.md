# ReaUI Designer

Create and revise editable UI design documents in ChatGPT desktop.

ReaUI Designer helps you create dashboards, app screens, landing pages, forms,
and multi-page UI designs. It validates static TSX pages and exports `.reaui`
documents and self-contained HTML previews. Open a document in a compatible
REA UI editor to keep editing its layers.

The plugin includes a local CLI and MCP server, supports reusable components,
offers editability suggestions, and can embed a design system in a document.
It requires local desktop execution and Node.js 22.18 or newer. Designs are
static documents. Embedded v4 design systems need a v4-compatible editor.

Source author: **xtcel**. The marketplace publisher name is the individual name
verified by OpenAI when the plugin is submitted.

ReaUI Designer is free and does not process purchases or payments. Design file
processing happens locally; the plugin does not upload design content to a
ReaUI server.

Examples:

- Design a 1280 × 900 task dashboard and export a validated `.reaui` file.
- Create home and settings screens for a mobile app at 390 × 844.
- Revise an existing `.reaui` design and generate an offline preview.
