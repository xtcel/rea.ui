## ADDED Requirements

### Requirement: 画布引用范围

引用画布元素时，系统 MUST 以被引用节点及其全部后代作为本轮唯一可改范围，MUST NOT 提供「仅自身 / 含子级」的模式切换。提示词 MUST 声明该范围，并要求范围外节点一律不可修改。

#### Scenario: 引用容器即包含子级

- **WHEN** 用户引用一个 `Frame`，其下有三层子节点
- **THEN** 注入提示词的引用块包含该 `Frame` 的 designId、父级路径、子级清单、className、文本与源码片段
- **AND** 提示词声明「下列元素及其全部子级是唯一可改范围」

#### Scenario: 子级改动计入本轮范围

- **WHEN** Agent 修改了被引用 `Frame` 的某个孙级节点的文本
- **THEN** 该改动被列为「本轮修改」，不进入「范围外改动」

#### Scenario: 引用节点之外的改动仍算范围外

- **WHEN** Agent 修改了与被引用节点同级的另一个节点
- **THEN** 该改动被列为「范围外改动」，只提示不拦截，可用 ⌘/Ctrl+Z 撤销

#### Scenario: 不再出现作用域开关

- **WHEN** 用户查看输入框上方的引用胶囊
- **THEN** 胶囊只提供移除操作，没有切换「仅自身 / 含子级」的按钮
- **AND** 悬停提示只显示「引用元素：<名称>」

#### Scenario: 旧会话仍可加载

- **WHEN** 会话文件里的引用记录带有历史字段 `subtree`
- **THEN** 该字段被忽略，引用正常加载，历史轮次只显示节点名称
