## ADDED Requirements

### Requirement: 设计系统生成与配置
系统 SHALL 支持使用 Codex 从描述与关联代码生成设计系统，并配置语义配色、字体、字号、间距、圆角、组件规范与使用指南。

#### Scenario: 提取项目规范
- **WHEN** 用户关联项目并提交设计系统生成需求
- **THEN** 生成草稿可预览和配置，保存后刷新仍保留

### Requirement: 预览和使用设计系统
系统 SHALL 提供基础样式、组件和指南预览，支持启用设计系统并设为默认，在 UI 生成前选择和传入对应规范。

#### Scenario: 应用配置
- **WHEN** 用户修改主色并使用此设计系统生成 UI
- **THEN** 预览同步更新，生成上下文包含所保存主色与组件规范
