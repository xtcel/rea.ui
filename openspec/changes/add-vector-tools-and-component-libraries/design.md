## Context

React/TSX → 静态解析 → DOM/SVG，Rust/WASM 提供无状态几何。已有多个未提交改动，实施不得覆盖。macOS 桌面 144% 已观察到文字和形状变软；现有全场景 transform scale 是待验证因素。

## Goals / Non-Goals

**Goals:** 交付 proposal 中四项能力；以 FigCraft 已有行为、算法、测试为参考。组件库为本机跨文档共享，固定版本、手动升级；组件、变体和插槽同属本次。

**Non-Goals:** 云端协作、布尔和分支网络、任意 React 代码执行；不重写已工作的布局/样式系统。

## Decisions

### 1. FigCraft 复用及适配

固定参考提交 `0e86f3597a7443b15c93ec3ab2091202f8802c95`。`crates/geom/src/lib.rs` 的 polygon/star、`canvas/tools/draw.rs` 的 Shift/Alt 规则、`tools/pen.rs` 的路径和平滑、`assets/components*` 的覆盖/变体/插槽、`assets/library.rs` 的发布快照为实施依据。优先抽取纯几何或移植有界子集，移植保留 LICENSE-MIT 与出处；不直接引入其依赖 Rust Document 的整套 engine。

### 2. 文档级组件声明与稳定地址

兼容当前页面文件，增加可选的 `components/main.components.tsx` 静态声明目录，根为 Components，含 Component 定义；每个定义恰有一个视觉根，属性/变体为静态字面量。Instance 只保存 component 引用、values、variant、overrides 和 SlotContent。库依赖以只读 TSX 定义及库 ID/版本快照进入同一目录。所有内容由 TSX 重建，不另存可独立编辑的设计 JSON。旧文档无需无编辑强制改写；首次组件操作再增加声明文件；归档协议升级必须显式识别版本。

渲染展开地址包含实例路径和定义节点身份，不按显示顺序寻址；普通页面节点保持现有 ID。实例内部编辑由命令路由为外层实例参数/覆盖，只有显式进入主组件编辑才写定义。SlotContent 是实例自己的真实源子树，有独立身份。展开后的树只读、可丢弃。

### 3. 形状与路径

Line 带首尾箭头参数；Polygon count=3 是三角形，Star 保存角数与内半径。参数化几何和可编辑路径互斥，转换是显式事务。Vector 保留 d/viewBox 兼容；新增静态路径锚点数据，稳定局部身份，支持直线/三次贝塞尔。d 由锚点派生，不同时作为两份权威数据。首期仅普通开放/闭合轮廓；圆弧转换必须有误差策略。描边命中宽容按屏幕像素除以 zoom，避免透明矩形挡住底层内容。

### 4. 缩放与测量

外层屏幕平移，内容层 CSS zoom，覆盖层屏幕坐标；显式 camera/context 代替解析 DOM transform 字符串。设计坐标不随相机变化，不入历史。先做 macOS 实测，覆盖 100/144/200/300%，再扩展至 800/1600%；浏览器与 DPR 1/2 检查布局、命中、文本覆盖层、旋转、吸附。CSS zoom 的布局影响是验证重点；未经验证不得宣称已根治。

### 5. 完整组件规则

主组件定义→属性绑定→已选多轴变体→实例属性覆盖；每个规范属性独立合并，禁止整串 className 覆盖丢失其他属性。实例外层位置独立，内部结构只允许主组件或插槽内容操作。绑定文字路由 values，普通文字路由 override；嵌套通过稳定路径定位。组件参数支持文字、布尔、有限数值、枚举、实例替换及嵌套暴露。变体组合必须唯一，不以随机或含混匹配回退。重置删除覆盖，分离生成新身份的普通子树，循环依赖拒绝。

### 6. 本地库

本地存储的库注册表和不可变发布快照；快照收集组件、嵌套依赖及资源。引用记录 libraryId/version/content hash，源文件未发布编辑不影响使用方。添加/搜索/插入/发布/升级在资源面板可用，首页设计系统关联库入口。升级先计算差异与不兼容项，用户显式接受后原子更新；保留兼容覆盖，删除插槽或属性的冲突不得静默丢弃。撤销恢复旧版本及覆盖。离线读取随文档携带的快照，文件往返保留依赖。

## Risks / Trade-offs

- CSS zoom 的测量差异 → 使用统一转换并在 macOS WKWebView 实测，不仅跑 jsdom。
- 现有页面 ID 仅页内唯一 → 组件定义身份和实例地址使用命名空间，不让跨页重名冲突。
- FigCraft 真实复制实例与 TSX 引用实例不同 → 复用规则和测试，展开树保持只读。
- 历史 proposal 仍写“仅 UI” → 本次批准扩展参考范围；长期单文件迁移与高级网络不因本次自动完成。
- 库破坏性更新 → 更新预览阻止含未解决冲突的升级，旧快照保持可读。

## Migration Plan

继续读取现有 v2；添加组件目录的新格式显式版本化，导入器同时支持旧档和新档，导出带全部依赖。备份原文；迁移失败不覆盖原记录。生成器说明和文档同步使用同一静态 Schema。

## Open Questions

产品范围无待确认项。CSS zoom 在 macOS 的实际改善、库快照大小和大文档性能由实施验证记录决定；不能以静态源码审查替代。
