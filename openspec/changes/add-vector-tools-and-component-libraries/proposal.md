## Why

现有编辑器缺少参数化形状和路径工具，macOS 桌面内容在放大时变软，也不能复用组件。用户于 2026-11-03 确认完整本地组件体系，并要求优先借鉴 FigCraft 的开源实现以提高效率。

## What Changes

- 增加线条、箭头、三角形、多边形、星形及对应参数面板。
- 增加钢笔、铅笔、贝塞尔锚点与控制柄编辑、路径转换和平滑。
- 修复 macOS DOM/SVG 内容放大模糊，统一视图坐标和屏幕覆盖层。
- 增加主组件、关联实例、属性、嵌套、覆盖/重置/分离、多轴变体及插槽。
- 增加本机跨项目/文档组件库：不可变发布版本、固定引用、更新预览及手动升级。
- 扩展静态 TSX 与文件往返；所有设计写入继续经过原子事务。
- 更新 FigCraft 复用边界：允许借鉴几何、交互、组件与库机制，不引入第二套可编辑设计真源。

## Capabilities

### New Capabilities
- `editable-vector-tools`: 参数化形状、钢笔、铅笔及节点编辑。
- `sharp-canvas-zoom`: 清晰缩放、统一坐标、独立覆盖层。
- `reusable-components`: 组件、实例、属性、变体、插槽及稳定寻址。
- `local-component-libraries`: 本地库发布、固定版本、依赖快照与升级。

### Modified Capabilities

无已归档基线。与长期变更 `react-source-design-editor` 的组件和矢量要求重叠，本变更负责本次确认范围，长期变更的完整网络、布尔、统一文件服务仍独立跟踪。

## Impact

涉及 design/document/geometry/renderer-dom/editor/storage、桌面兼容验证及生成器格式说明。复用 FigCraft 提交 `0e86f3597a7443b15c93ec3ab2091202f8802c95`，移植代码保留许可及来源。

## 范围说明

本次完整组件体系包含多轴变体、插槽和本地跨文档库；分阶段仅表示实施顺序。团队云端、多人协作、分支矢量网络、布尔运算及任意业务 React 执行不在本次范围。保持现有页面文件兼容，文档级组件声明使用独立 TSX 目录文件；不以本次交付为由强制重写全部已有布局和文档协议。
