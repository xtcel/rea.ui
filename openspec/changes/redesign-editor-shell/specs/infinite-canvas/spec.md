## ADDED Requirements

### Requirement: 单页多画框的无限画布
画布 SHALL 把当前页面渲染为无限画布，同时显示页面中的所有画框和游离图层。画框的位置与尺寸 MUST 取自其 className（见 `document-model`）。页面的背景色取自 `<Page className>`。

#### Scenario: 同时显示多个画框
- **WHEN** 页面有位置不同的 Desktop 与 Mobile 两个画框
- **THEN** 两个画框同时显示在画布上各自的位置，彼此不重叠地展示

#### Scenario: 游离图层
- **WHEN** 页面上有一个不在任何画框内的矩形
- **THEN** 它显示在画布上，没有画框标题

#### Scenario: 页面背景
- **WHEN** `<Page className="bg-[#F5F5F5]">`
- **THEN** 画布背景为 `#F5F5F5`

### Requirement: 画框标题与尺寸标签
每个画框 SHALL 在左上角外侧显示标题（画框名称）。标题的字号 MUST 不随画布缩放变化；缩放比例小于 25% 时 SHOULD 隐藏标题。点击标题 MUST 选中该画框；选中画框时标题高亮。选中图层时 SHALL 在选框下方显示尺寸标签（宽 × 高），尺寸标签的字号也不随缩放变化。

#### Scenario: 点击标题选中画框
- **WHEN** 点击画框 `Desktop` 的标题
- **THEN** 该画框被选中，标题高亮

#### Scenario: 标题大小恒定
- **WHEN** 画布缩放从 100% 变为 50%
- **THEN** 标题的屏幕字号保持不变

#### Scenario: 尺寸标签
- **WHEN** 选中一个 320×200 的矩形
- **THEN** 选框下方显示 `320 × 200`

### Requirement: 缩放、平移与适应
画布 SHALL 支持：滚轮平移；`Ctrl/⌘ + 滚轮` 按指针位置缩放；`H` 工具、按住空格拖动或鼠标中键拖动平移；缩放范围 10%–300%；快捷键 `+` / `-` 缩放，`Shift+1` 适应全部内容，`Shift+2` 适应选中对象，`Shift+0` 缩放到 100%。缩放下拉 SHALL 提供对应的菜单项并显示快捷键。

#### Scenario: 适应全部
- **WHEN** 按 `Shift+1`
- **THEN** 画布缩放并平移到页面所有画框和游离图层刚好完整可见

#### Scenario: 适应选中
- **WHEN** 选中 Mobile 画框后按 `Shift+2`
- **THEN** 画布缩放并平移到该画框刚好完整可见

#### Scenario: 缩放上下限
- **WHEN** 持续放大画布
- **THEN** 缩放比例不超过 300%；持续缩小不低于 10%

### Requirement: 页面切换时的相机
切换页面时，画布 SHALL 恢复该页面在本次会话内上一次的相机位置；该页面第一次显示、或新建页面时 MUST 自动适应全部内容。

#### Scenario: 来回切换页面
- **WHEN** 在页面 A 缩放到 50% 后切换到页面 B，再切回页面 A
- **THEN** 页面 A 的缩放仍是 50%，位置不变

#### Scenario: 首次显示自动适应
- **WHEN** 第一次打开一个页面
- **THEN** 画布自动适应显示该页面的全部内容

### Requirement: 空页面状态
页面没有任何画框或图层时，画布 SHALL 显示空状态提示，说明按 `F` 或点击工具栏的画框工具创建画框。

#### Scenario: 空页面
- **WHEN** 打开一个新建的空页面
- **THEN** 画布中央显示「按 F 创建画框」的提示，创建第一个画框后提示消失

### Requirement: 画框工具与图层工具的放置规则
画框工具（F）SHALL 在画布任意位置拖动创建新画框；创建的画框成为页面的顶层画框，默认带 `overflow-hidden` 与白色背景，名称为「画框 N」。矩形 / 椭圆 / 文字工具 SHALL 在拖动起点所在的最深层画框内创建子图层；起点在所有画框之外时创建页面的游离图层。单击而不拖动时，MUST 使用默认尺寸（画框 960×640，文字 280×48，其他 160×120）。创建完成后工具 MUST 自动回到移动工具。

#### Scenario: 在画布空白处创建画框
- **WHEN** 选择画框工具并在空白处拖出一个矩形区域
- **THEN** 页面新增一个顶层画框，位置与尺寸等于拖出的区域，并被选中

#### Scenario: 在画框内创建矩形
- **WHEN** 选择矩形工具并在 Desktop 画框内拖动
- **THEN** 矩形成为 Desktop 的子图层，坐标相对于该画框

#### Scenario: 在画框外创建矩形
- **WHEN** 选择矩形工具并在所有画框之外拖动
- **THEN** 矩形成为页面游离图层

#### Scenario: 单击使用默认尺寸
- **WHEN** 选择文字工具并在画框内单击
- **THEN** 创建一个 280×48 的文字图层

### Requirement: 画布交互沿用并适配新模型
选择、拖动、八方向缩放和 `Shift` 吸附网格 SHALL 在新模型上继续可用：被选中节点的位置与尺寸通过修改其 className 写入；拖动或缩放过程中只在会话里预览，释放时提交一个事务；`Esc`、指针取消和窗口失焦 MUST 取消进行中的手势。

#### Scenario: 拖动提交一个历史项
- **WHEN** 拖动一个矩形并释放
- **THEN** 矩形 className 中的 `left-*`、`top-*` 被更新，撤销一次回到拖动前

#### Scenario: Esc 取消拖动
- **WHEN** 拖动过程中按 `Esc`
- **THEN** 矩形回到原位置，历史没有新增

#### Scenario: 缩放写入尺寸
- **WHEN** 拖动手柄把矩形缩放为 200×100
- **THEN** className 中的 `w-*` 与 `h-*` 被更新为对应的值
