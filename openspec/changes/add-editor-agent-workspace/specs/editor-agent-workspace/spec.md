## ADDED Requirements

### Requirement: 创建项目后启动设计

系统 SHALL 在用户从首页提交有效 AI 设计需求时先创建并保存项目，打开编辑器并显示左侧 AI 会话，然后启动 Agent；后续轮次 MUST 修改同一项目。

#### Scenario: 首页首次设计
- **WHEN** 用户提交设计需求且项目保存成功
- **THEN** Agent 启动前项目已存在，编辑器显示首轮需求与设计画布

#### Scenario: 项目创建失败
- **WHEN** 本地存储拒绝创建项目
- **THEN** 系统不启动 Agent，保留需求并显示创建错误

### Requirement: 项目内会话与公开执行过程

系统 SHALL 在编辑器左侧提供 AI 会话，展示用户需求、公开进度、文件操作、校验和结果摘要，支持与图层和资源切换且不因标签切换中断任务；系统 MUST 忽略内部 reasoning 事件。

#### Scenario: 查看执行进度
- **WHEN** Agent 读取页面或编辑页面文件
- **THEN** 会话展示相应操作摘要，并允许展开执行记录

#### Scenario: 恢复同一项目
- **WHEN** 用户重新打开已有会话的项目
- **THEN** 恢复该项目最近会话，上次未完成的轮次标记为中断，不自动重复发起请求

#### Scenario: 窄屏使用
- **WHEN** 用户在窄屏进入 AI 设计
- **THEN** 可以打开 AI 抽屉、收起抽屉查看画布，且页面不横向溢出

### Requirement: 设计文件工作区与协议

系统 SHALL 将当前项目清单、页面与可选组件源复制到临时工作区，向 Agent 注入静态格式、保留已有 designId、设计系统与资产路径索引的协议。样式 MUST 使用静态 Tailwind className，例如 `absolute left-0 top-0 w-[1440px] h-[1024px] bg-white`，禁止动态代码、事件、HTML 和内联 style。

#### Scenario: 编辑现有设计
- **WHEN** 用户要求调整已有按钮
- **THEN** Agent 可读取当前页面并局部修改，协议要求保留该按钮及未修改图层的 designId

#### Scenario: 关联代码参考
- **WHEN** 用户关联本地代码项目
- **THEN** 资料作为只读上下文传入，Agent 的可写工作目录仍为临时设计目录

### Requirement: 生成中同步有效页面

系统 MUST 在 Agent 运行中读取文件快照，仅将通过 DocumentSession 静态校验的快照原子提交至当前项目，更新画布、图层与自动保存；页面、项目身份和非设计文件 MUST 保持一致。

#### Scenario: 分阶段生成
- **WHEN** Agent 在完成之前保存了有效页面，稍后再追加有效区域
- **THEN** 右侧先显示第一次有效设计，再显示后续更新，无需等待任务结束

#### Scenario: 无效更新
- **WHEN** 中间快照出现重复 designId、非法事件或不完整 TSX
- **THEN** 画布仍显示最后有效设计且不执行输出代码

### Requirement: 自动修复与有限重试

系统 SHALL 在最终设计校验失败时将错误反馈给 Agent，最多自动修复一次；第二次失败 MUST 保留最后有效设计并显示错误与重试入口。

#### Scenario: 首次输出校验失败
- **WHEN** Agent 完成任务但最终页面未通过 AST 校验
- **THEN** 会话展示自动修复状态，并将错误和失败文件反馈到下一次请求

### Requirement: 原子历史与并发保护

系统 MUST 为同一轮连续 AI 更新保留一个可撤销历史步骤，并在文档身份或 revision 不符合预期时拒绝后续更新。

#### Scenario: 撤销一次 AI 设计
- **WHEN** 一轮 AI 设计同步了多次页面后用户执行撤销和重做
- **THEN** 一次撤销恢复本轮前设计，一次重做恢复本轮最后有效设计

#### Scenario: 用户手动编辑
- **WHEN** AI 运行中用户手动修改、撤销或切换文档
- **THEN** 旧任务停止应用更新并提示基于当前设计重新发送需求

### Requirement: 停止和错误恢复

系统 SHALL 支持在参考准备和生成过程中停止，取消后 MUST 保留项目和已同步的有效设计；未完成任务的迟到响应不得应用。

#### Scenario: 生成中停止
- **WHEN** 用户点击停止
- **THEN** 后端任务取消，会话标记已停止，已同步设计仍可编辑和导出

### Requirement: 工作区边界和封包兼容

系统 MUST 限制工作区文件数量与大小，拒绝路径穿越及符号链接；同步设计 SHALL 能经现有 `.reaui` 导出导入恢复。

#### Scenario: 非法页面路径
- **WHEN** 工作区清单引用越出 pages 目录的文件或符号链接
- **THEN** 宿主拒绝快照且不读取目标内容

#### Scenario: 保存与重新导入
- **WHEN** 用户导出 AI 生成的项目并重新导入
- **THEN** 页面和有效设计修改保持一致，仍可通过普通编辑器事务修改
