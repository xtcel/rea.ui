## Context

`HomeApp.send` 当前在首页调用只读 Codex 任务，接收完整 JSON 并验证后通过 `openGenerated` 创建新文档。`EditorWorkspace` 只有图层/资源左栏与属性右栏。`DocumentSession` 提供源码事务和撤销记录，IndexedDB 与 `.reaui` 已负责持久化和交换。

## Goals / Non-Goals

**Goals:** 先建项目再运行 Agent；同屏显示会话与设计；允许 Agent 理解并直接编辑现有静态文件；逐步验证、原子提交、自动保存和单轮撤销；支持恢复会话与连续修改。

**Non-Goals:** 通用 MCP Server、外部 CLI 封包工具、执行生成代码、云端账号、共享协作、逐 token 渲染不完整 TSX、展示内部思维链。

## Decisions

### 1. 项目与会话生命周期

首页提交先调用 `model.create`，持久化成功后进入带 AI 标签的编辑器，把首轮需求、设计系统与参考作为启动请求传给面板。会话记录以文档 ID 存入 IndexedDB 元数据，后续轮次使用当前项目设计文件与近期对话。刷新、离开编辑器或切换项目时取消旧任务；已创建项目与最后有效设计保留。

### 2. 临时文件目录作为 Agent 适配层

继续复用 Codex CLI 的文件读取与编辑工具。宿主在临时 `design/` 中写入清单、页面、可选组件目录与 `AGENTS.md`，以该目录作为 `workspace-write` 的工作目录。关联项目资料预先读取到提示词，不把关联目录设为可写工作目录。设计系统提取等旧任务继续使用只读模式。

相较全量 JSON 返回，此模式可在每次完整文件保存后同步画布，且后续只需局部修改已有源。相较新增 MCP 语义工具，此模式复用现有文件协议与 Agent 工具能力，减少首版接口数量；后续仍可在相同的静态校验和事务边界上增加图层工具。

### 3. 协议注入与公开进度

提示词和规则文件说明静态 `@rea/design` 原语白名单、`designId` 保留、清单身份、Tailwind v4 类、组件目录、资产路径索引与标准示例。Agent 每完成一个区域就保存完整有效页面，最终只返回简短 summary。进度从公开 Agent 消息与工具执行事件提炼；忽略 reasoning 类型，不转发原始命令输出。

### 4. 快照、校验与原子更新

Rust 轮询临时目录，状态响应携带最新文件快照。只读取清单指定的固定页面路径及固定组件目录，限制 12 页、每个文件 500KB、序列化快照 2MB，拒绝路径穿越和符号链接。前端只在快照变化时构造 `DocumentSession`，验证成功后写入同一文档；保留宿主中的非设计文件与资产。

`DocumentSession.replaceSources` 校验全部候选并维护历史；连续同轮快照以 turn ID 合并，撤销恢复该轮开始前的状态。提交时检查文档 ID 与预期 revision，手动编辑、撤销或切换项目后拒绝应用旧结果并取消任务。相机与选区继续由编辑器维护。

### 5. 失败、修复与取消

不完整或非法快照仅产生校验等待状态，画布保留最后有效快照。若任务结束仍无有效最终快照，将错误与失败源作为资料重新请求一次修复，修复仍失败则显示可操作错误并保留需求。连接、进程和网络失败不自动循环重试。停止支持参考准备及实际生成阶段，且取消返回后不应用后续结果。

### 6. 布局与视觉约束

沿用白色平面侧栏、灰色画布、蓝色操作状态、系统字体和 Lucide 图标。左栏新增“AI / 图层 / 资源”，AI 默认宽度 360px，可调整；切换标签保留任务。右侧保持可视化画布与属性检查。窄屏使用既有互斥抽屉，首轮自动打开 AI 抽屉并允许收起查看画布。

## Risks / Trade-offs

- 文件保存之间可能出现半写入状态 → 只发布完整且通过 AST 校验的快照；最终缺文件必须报错而非回退为成功。
- Agent 可能一直不保存或未改文件 → 明确分区保存协议；验收用运行中的文件写入证明中途可见，不将最终一次渲染称作实时生成。
- 手动修改与 Agent 更新冲突 → revision 守卫停止旧任务，不尝试隐式合并。
- 多次 AST 解析开销 → 宿主快照有大小上限，前端对相同快照去重；UI 以约 800ms 查询进度。
- 历史与会话体积增长 → 会话保留最近 40 轮，公开进度有界；同一轮快照合并为一个撤销步骤。
- 本地 CLI 运行环境差异 → 同时验证 Rust 假 Agent 集成和浏览器流程；真实 Codex 验证单独注明覆盖范围。

## Migration Plan

无需迁移 `.reaui` 格式。会话元数据使用新键，不改变已有项目；保留旧 `uiSchema/generatedDocument` 供设计系统及既有生成契约测试使用。发布后首页默认进入新流程，原有项目可直接在左栏启动 AI 编辑。
