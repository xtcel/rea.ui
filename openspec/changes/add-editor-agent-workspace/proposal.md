## Why

当前 AI 设计停留在首页等待，完成后才创建文档，用户无法在编辑器里观察生成进度或连续修改同一项目。需要让项目先存在，让 AI 会话与可编辑画布共同构成设计工作区，并通过静态设计文件连接 Agent 与编辑器。

## What Changes

- 首页提交设计需求后先创建并持久化项目，立即打开编辑器，再启动 Agent。
- 编辑器左栏增加 AI 会话，与图层、资源切换；显示需求、公开执行摘要、文件操作、校验和同步状态，支持连续对话、停止、重试与按项目恢复会话。
- 给本地 Agent 提供临时设计目录，注入静态 TSX 协议、设计系统、现有页面及参考资料，支持直接读取和编辑设计文件。
- 生成过程中读取文件快照，经 DocumentSession 校验后原子更新同一项目的画布、图层和自动保存；同一轮连续更新合并为一次撤销。
- 无效快照不进入画布，最终校验失败时自动修复一次；手动编辑或切换项目后停止应用旧任务更新。
- 延续现有 `.reaui` 导入、导出和资源保存链路。

## Capabilities

### New Capabilities

- `editor-agent-workspace`: 先创建项目、编辑器内的持久会话、文件工作区、实时验证和画布同步。

### Modified Capabilities

无。当前 `local-agent-generation` 尚位于未归档变更 `add-local-agent-ui` 中；本变更承接其能力，AI 设计入口采用本文定义的新流程，设计系统生成仍沿用原流程。

## Impact

首页与编辑器外壳、Agent 面板与任务客户端、DocumentSession 外部源码事务、文档自动保存、Rust 本地 Agent 运行库及 Vite 桥接。无需引入第二套设计模型或新增运行时依赖。

## 范围说明

本次实现本机 Codex 的文件交互方案；不新增通用 MCP Server、外部 unpack/pack CLI、云端协作或任意 React 执行能力。界面中的“执行过程”是公开进度、操作和结果摘要，不展示模型内部思维链。关联代码仅提供读取后的上下文，Agent 的可写工作目录为临时设计目录。
