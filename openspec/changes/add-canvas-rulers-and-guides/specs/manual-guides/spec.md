## ADDED Requirements

### Requirement: 手动参考线的数据模型与文档持久化

手动参考线 SHALL 按页面保存在文档元数据文件 `editor/guides.json` 中，结构为 `{ version: 1, pages: { [pageId]: { id, axis: "x" | "y", position }[] } }`；`axis: "x"` 表示垂直参考线（世界 x），`axis: "y"` 表示水平参考线（世界 y），`position` MUST 是有限数字并取整到设计 px。系统 MUST NOT 把参考线写入页面 TSX、`rea.json` 或代码导出结果；写入 MUST 走 `DocumentSession.withMetadata()`，即不进入撤销 / 重做历史。

#### Scenario: 按页面隔离

- **WHEN** 页面 A 有 x=120 的参考线，切换到没有参考线的页面 B
- **THEN** 画布只显示页面 B 的参考线（空），切回 A 时 x=120 的参考线仍在

#### Scenario: 跨刷新保留

- **WHEN** 创建参考线后刷新页面并重新打开同一文档
- **THEN** 参考线仍在原世界坐标位置

#### Scenario: `.reaui` 往返

- **WHEN** 导出含参考线的文档并重新导入
- **THEN** 新文档按页面恢复全部参考线，且设计源文件逐字节不变

#### Scenario: 数据不进撤销历史

- **WHEN** 删除一条参考线后按 `⌘/Ctrl+Z`
- **THEN** 撤销的是最近一次设计编辑，参考线不会被恢复

#### Scenario: 页面删除后的清理

- **WHEN** 删除页面 A 后再次编辑任意参考线
- **THEN** `pages.A` 条目被清理，文件中不含已删除页面的数据

### Requirement: 数据校验与容错

`parseGuides()` SHALL 校验 version、页面 id、axis、position 有限性与每页最多 200 条；文件大小 MUST 不超过 64KB。非法条目、未知字段、未知页面 MUST 被丢弃而不是导致编辑器报错；导入 `.reaui` 时损坏或超大的 `editor/guides.json` MUST 被丢弃并给出 warning，且 MUST NOT 阻断文档导入。

#### Scenario: 损坏文件

- **WHEN** 导入的 `.reaui` 中 `editor/guides.json` 不是合法 JSON
- **THEN** 文档正常导入，参考线为空，警告中说明已忽略参考线文件

#### Scenario: 非法坐标

- **WHEN** 元数据中有一条 `position: "abc"` 或 `position: null` 的记录
- **THEN** 该条被忽略，同页其余合法参考线正常显示

#### Scenario: 上限保护

- **WHEN** 某页参考线达到 200 条后继续拖出新线
- **THEN** 系统给出提示且不新增，已有参考线不变

### Requirement: 从标尺单击或拖出创建参考线

在标尺上**单击** SHALL 立即新增一条垂直于该标尺的参考线：顶部标尺产生垂直参考线（`axis: "x"`，位置取点击处的世界 x），左侧标尺产生水平参考线（`axis: "y"`，位置取点击处的世界 y）。按住标尺并**向画布方向拖出** SHALL 改为按拖动方向创建（顶部标尺拖出水平参考线、左侧标尺拖出垂直参考线），拖拽期间 MUST 显示参考线预览与坐标徽标（如 `x 120`）。松手落在画布外 MUST 取消创建；拖出后又被拖回同一标尺条带再松手 MUST 取消创建。坐标 MUST 按设计 px 取整，按住 `Shift` 时 MUST 按 8px 网格取整。即使「显示参考线」处于关闭状态，创建动作也 MUST 被接受：系统 SHALL 自动开启「显示参考线」并继续创建，MUST NOT 静默忽略该手势。

#### Scenario: 单击顶部标尺即建线

- **WHEN** 在世界 x ≈ 120.4 处单击顶部标尺且不移动指针
- **THEN** 新增 `axis: "x", position: 120` 的垂直参考线，无需拖动

#### Scenario: 单击左侧标尺即建线

- **WHEN** 在世界 y = 64 处单击左侧标尺且不移动指针
- **THEN** 新增 `axis: "y", position: 64` 的水平参考线

#### Scenario: 从标尺拖出创建

- **WHEN** 从顶部标尺按下并拖到世界 y = 300 处松手
- **THEN** 新增 `axis: "y", position: 300` 的水平参考线

#### Scenario: 取消创建

- **WHEN** 从标尺按下后拖出画布再拖回标尺条带并松手
- **THEN** 不产生参考线，元数据文件不发生变化

#### Scenario: Shift 网格

- **WHEN** 按住 `Shift` 拖到世界 x = 123 并松手
- **THEN** 参考线位置为 120（8px 网格取整）

### Requirement: 从菜单添加参考线

标尺关闭时用户 MUST 仍能添加参考线：顶栏「视图」菜单与画布空白处右键菜单 SHALL 各自提供「添加垂直参考线」「添加水平参考线」。画布右键 MUST 使用右键落点的世界坐标定位；顶栏菜单 MUST 使用当前视口中心定位。添加 MUST 遵守每页 200 条上限并在超限时提示。若「显示参考线」处于关闭状态，添加动作 MUST 自动开启显示，避免出现「添加成功但看不见」的结果。

#### Scenario: 从画布右键添加

- **WHEN** 在世界坐标 (320, 180) 处右键并选择「添加水平参考线」
- **THEN** 页面新增 `axis: "y", position: 180` 的水平参考线并立即显示

#### Scenario: 标尺关闭时从视图菜单添加

- **WHEN** `showRulers` 为 false，从顶栏「视图」菜单选择「添加垂直参考线」
- **THEN** 在视口中心的世界 x 处新增垂直参考线，标尺保持关闭

#### Scenario: 隐藏状态下添加自动显示

- **WHEN** `showGuides` 为 false 时从任一菜单添加参考线
- **THEN** 「显示参考线」自动变为开启，新参考线立即可见

#### Scenario: 上限提示

- **WHEN** 某页已有 200 条参考线时继续添加
- **THEN** 给出上限提示且不新增任何参考线

### Requirement: 拖拽修改与拖出画布删除

已有参考线 SHALL 提供 8px 宽的屏幕空间命中带，可直接拖动改位置；拖拽中 MUST 显示坐标徽标，`Esc` / `pointercancel` / `lostpointercapture` / 窗口失焦 MUST 取消并恢复拖动前位置。删除 MUST 采用「沿参考线法线方向拖出画布」：垂直参考线拖出画布左右边界、水平参考线拖出画布上下边界即进入删除区，进入后 MUST 显示「松开删除」提示，松手 MUST 删除。参考线在画布内松手 MUST 只更新位置，MUST NOT 因为靠近画布边缘而被删除。正在拖拽的参考线 MUST 保持挂载，即使其位置已经移出视口——卸载会丢失指针捕获并中断手势。参考线的 `pointerdown` MUST NOT 冒泡为图层手势。

#### Scenario: 拖动改位置

- **WHEN** 把 x=120 的垂直参考线拖到 x=240 并松手
- **THEN** 该参考线位置更新为 240，其他参考线不变，元数据只写入一次

#### Scenario: 拖出画布删除

- **WHEN** 把一条垂直参考线拖到画布右边界之外并松手
- **THEN** 该参考线被删除并写入元数据；水平的同理，拖出上边界或下边界即删除

#### Scenario: 拖到画布边缘不删除

- **WHEN** 把垂直参考线拖到画布内靠近左边缘处松手（指针仍在画布内）
- **THEN** 只更新位置，参考线不被删除

#### Scenario: 删除提示

- **WHEN** 拖拽中的参考线被拖到画布之外
- **THEN** 线变为半透明并显示「松开删除」提示；拖回画布内后提示消失、松手只改位置

#### Scenario: 移出视口仍保持拖拽

- **WHEN** 把水平参考线向上拖到屏幕顶部之外（其屏幕坐标已超出视口）
- **THEN** 参考线元素保持挂载、拖拽不中断，松手仍按删除区规则处理

#### Scenario: Esc 取消

- **WHEN** 拖动参考线到一半按 `Esc`
- **THEN** 参考线回到拖动前位置，没有新增元数据写入，也没有影响图层选区

#### Scenario: 命中带宽度恒定

- **WHEN** 画布缩放为 50% 与 200%
- **THEN** 参考线命中带始终是屏幕 8px，视觉线宽始终是屏幕 1px

### Requirement: 参考线渲染与可见性

参考线 SHALL 以屏幕空间 1px 实线贯穿画布视口，颜色使用 `--rea-manual-guide`（`#7c3aed`），与智能参考线 `#c52b76`、间距标注 `#b43b12` 区分；覆盖层 MUST 位于设计内容之上，与智能参考线分属两个独立覆盖层，且默认 `pointer-events: none`（仅命中带接收事件）。视口外的参考线 MUST NOT 渲染但仍保留在数据中（正在拖拽的那条除外）。`showGuides` 为 false 时参考线 MUST 全部隐藏且不可拖拽；`showRulers` 为 false 时 MUST NOT 影响参考线的显示与拖动。

#### Scenario: 缩放和平移

- **WHEN** 缩放或平移画布
- **THEN** 参考线始终贴合其世界坐标对应的屏幕位置，线宽不变

#### Scenario: 视口外参考线

- **WHEN** 一条 x=5000 的参考线不在当前视口内
- **THEN** 画布不绘制它，平移到该坐标附近后重新出现

#### Scenario: 关闭显示参考线

- **WHEN** 关闭「显示参考线」且页面已有 3 条参考线
- **THEN** 3 条参考线全部隐藏且无法拖动，重新开启后原位置恢复

#### Scenario: 只关闭标尺

- **WHEN** 保持「显示参考线」开启、关闭「显示标尺」且页面已有 3 条参考线
- **THEN** 3 条参考线仍可见、可拖动，拖出画布边界即被删除（与标尺开关无关）

#### Scenario: 标尺隐藏时删除路径一致

- **WHEN** `showRulers` 为 false，把一条垂直参考线拖出画布右边界
- **THEN** 显示「松开删除」提示，松手后该参考线被删除

### Requirement: 右键删除与清除

画布右键菜单 SHALL 提供「清除当前页面参考线」（无参考线时禁用）；在参考线上右键 SHALL 提供「删除此参考线」。清除 / 删除 MUST 立即写入元数据并给出短提示，MUST NOT 进入撤销历史。

#### Scenario: 清除当前页面

- **WHEN** 页面 A 有 3 条参考线时选择「清除当前页面参考线」
- **THEN** 页面 A 参考线清空，其他页面参考线不受影响

#### Scenario: 单条删除

- **WHEN** 在某条参考线上右键并选择「删除此参考线」
- **THEN** 只删除该条，且不会改变图层选区
