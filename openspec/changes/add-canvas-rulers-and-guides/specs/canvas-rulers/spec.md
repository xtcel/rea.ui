## ADDED Requirements

### Requirement: 顶部与左侧标尺

开启「显示标尺」后，画布 SHALL 在顶部与左侧各显示一条 20px 厚的标尺，以及左上角 20×20 的角块。标尺 MUST 是固定在屏幕空间的覆盖层，不随设计内容缩放；标尺 MUST NOT 改变 `.rea-canvas` 容器的尺寸、位置或 `screenToWorld()` / `worldPoint()` 的坐标契约。关闭开关时两条标尺与角块 MUST 全部隐藏。

#### Scenario: 默认关闭

- **WHEN** 首次打开一个页面，偏好中没有任何显式设置
- **THEN** `showRulers` 为 false，画布不显示标尺与角块

#### Scenario: 手动开启显示

- **WHEN** 通过独立「视图」菜单开启「显示标尺」
- **THEN** 画布顶部与左侧各出现一条标尺，左上角为不带刻度的角块

#### Scenario: 关闭标尺不影响参考线

- **WHEN** 页面已有参考线，且 `showGuides` 为 true 时关闭「显示标尺」
- **THEN** 两条标尺与角块消失，参考线仍保持可见与可拖动，画布内容的位置和缩放比例不变

#### Scenario: 缩放不影响标尺厚度

- **WHEN** 画布缩放从 100% 变为 300%
- **THEN** 标尺仍为屏幕 20px 厚，刻度读数按新的 `zoom` 重新计算

### Requirement: 刻度读数与密度

标尺 SHALL 以「标尺原点」为 0 点、以设计 px 为单位显示刻度，原点默认为页面世界坐标 (0,0)；刻度位置 MUST 使用 `screen = world * zoom + camera.x|camera.y`，标签值 MUST 为 `world - origin`。系统 SHALL 从 1/2/5/10/20/50/100/200/500/1000/2000/5000 序列中选取满足 `step * zoom >= 8px` 的最小步长作为次刻度，主刻度步长为次刻度的 10 倍并显示数字标签；负坐标 MUST 带负号显示。刻度文字 MUST 使用固定 10px 屏幕字号（等宽数字），MUST NOT 使用 CSS `zoom`。顶部（x 轴）标尺文字 SHALL 保持水平；左侧（y 轴）标尺文字 MUST 沿标尺方向竖向排列（逆时针旋转 90°、自下而上阅读）并以其刻度位置为中心，MUST NOT 因 20px 条带宽度而折行或被截断。标尺 0 点 MUST 固定为页面世界坐标 (0,0)，系统 MUST NOT 提供任何改变 0 点位置的手势或入口；平移与缩放只改变刻度的屏幕位置，MUST NOT 改变刻度读数。

#### Scenario: 100% 下的主刻度

- **WHEN** `zoom = 1`、`camera.x = 80`，页面世界原点在视口内
- **THEN** 顶部标尺在屏幕 x = 80、180、280… 处显示 `0`、`100`、`200`… 标签，中间有 10px 间隔的次刻度

#### Scenario: 平移后 0 点跟随

- **WHEN** 画布向右平移 40px
- **THEN** 世界 0 点的标签移动到屏幕 x = 120，其余刻度同步平移

#### Scenario: 负坐标

- **WHEN** 视口左侧对应世界 x = -150
- **THEN** 标尺在该区域显示 `-200`、`-100` 等带负号的读数

#### Scenario: 缩小到 10%

- **WHEN** 缩放为 10%
- **THEN** 次刻度步长自动放大，屏幕上的刻度间距不小于 8px，且标签数字仍是设计 px 值而非屏幕 px 值

#### Scenario: 放大到 300%

- **WHEN** 缩放为 300%
- **THEN** 次刻度步长自动缩小，标签不重叠且仍以设计 px 标注

#### Scenario: 左侧标尺的多位数读数

- **WHEN** 左侧标尺出现 `-1000` 等四位数及以上的读数
- **THEN** 文字沿标尺竖向排布、自下而上阅读，完整显示且不折行、不超出 20px 条带；顶部标尺的同值读数仍为水平文字

### Requirement: 指针位置指示

系统 MUST NOT 在画布内移动指针时持续在标尺上显示位置指示线（早期实现的「跟随鼠标的短标记」已移除），标尺只承担刻度与读数。取而代之的两种提示 MUST 如下，标尺覆盖层默认 MUST 为 `pointer-events: none`，仅标尺条带自身接收指针事件：

1. **悬停预览**：指针进入标尺条带并移动时，SHALL 在与该标尺垂直的方向上预览「此时单击会落下的参考线」——顶部标尺给出垂直预览线（世界 x）、左侧标尺给出水平预览线（世界 y），并显示坐标徽标；指针离开条带 MUST 立即移除预览。预览 MUST NOT 写入文档数据、不可拖动、不参与吸附，也不进入撤销历史。`showGuides` 为 false 时预览 MUST 仍然显示（它说明的是「点击会创建什么」），此时既有参考线保持隐藏。
2. **拖拽落点标记**：正在拖动一条已有参考线（或正从标尺拖出创建）期间，标尺条带 MUST 在该参考线的位置上显示一段短标记，使落点读数可读；拖拽结束或取消后 MUST 移除。

#### Scenario: 悬停预览的方向

- **WHEN** 指针移入顶部标尺并停在世界 x ≈ 301 处
- **THEN** 出现一条贯穿画布高度的垂直预览线，位置对齐刻度 `301`，并显示 `x 301` 徽标；指针移回画布后预览消失

#### Scenario: 悬停不产生数据

- **WHEN** 在标尺上移动指针若干次但从不按下
- **THEN** 页面参考线数量不变，`editor/guides.json` 不产生写入

#### Scenario: 关闭显示参考线时仍然预览

- **WHEN** `showGuides` 为 false 时把指针移入顶部标尺
- **THEN** 预览线照常出现，既有参考线仍然隐藏；在标尺上单击后「显示参考线」被自动开启且新线可见

#### Scenario: 画布内移动无指示

- **WHEN** 指针只在画布内移动、不进入标尺条带
- **THEN** 两条标尺上都没有任何随指针移动的标记

#### Scenario: 拖动参考线时的落点标记

- **WHEN** 拖动一条垂直参考线并经过世界 x ≈ 420
- **THEN** 顶部标尺在 `420` 处显示短标记；松手后标记消失

#### Scenario: 不遮挡画布点击

- **WHEN** 标尺开启，在标尺覆盖层之外单击一个图层
- **THEN** 该图层被正常选中，覆盖层不拦截命中测试

### Requirement: 标尺手势的分流与固定的 0 点

标尺上的指针手势 SHALL 按方向分流，与 Sketch 一致：移动距离小于 4px 视为**单击**，由上层创建垂直于该标尺的参考线；向画布方向（跨轴）拖动 MUST 创建参考线；沿标尺轴向拖动 MUST 不产生任何效果。标尺 0 点 MUST 恒为页面世界坐标 (0,0)：系统 MUST NOT 提供「拖动原点」「锁定原点」「重置原点」之类的手势或菜单入口，MUST NOT 存在可平移读数的会话状态。拖拽进行中的标尺 MUST 有明确光标与无障碍名称，标尺上的 `pointerdown` MUST NOT 冒泡为画布的图层选择 / 框选手势。

#### Scenario: 单击与拖动的分流

- **WHEN** 在顶部标尺上原地按下松开
- **THEN** 创建一条垂直参考线，刻度读数不变

#### Scenario: 沿轴拖动不改变刻度

- **WHEN** 在顶部标尺上按下并横向拖动 900px（缩放 10%）
- **THEN** 不创建参考线、不移动 0 点，刻度仍按世界坐标读数；页面世界 0 处仍显示 `0`（不得出现 `-9000` 一类的偏移读数）

#### Scenario: 平移与缩放只移动刻度位置

- **WHEN** 平移画布或改变缩放后，页面世界 0 点仍落在视口内
- **THEN** 该位置的刻度标签仍为 `0`，其余标签为对应的世界坐标；参考线与图层坐标不变

#### Scenario: 标尺关闭时没有拖出入口

- **WHEN** `showRulers` 为 false 时在画布左上角按下并拖动
- **THEN** 走普通画布手势，不会出现参考线预览

### Requirement: 标尺右键菜单

右键单击顶部标尺 SHALL 提供「删除所有垂直参考线」，右键单击左侧标尺 SHALL 提供「删除所有水平参考线」，右键单击左上角块 SHALL 提供「清除所有参考线」；三者 MUST 同时提供「显示标尺」「显示参考线」两个开关，且 MUST NOT 提供任何改变标尺 0 点的入口。对应方向没有参考线时删除项 MUST 禁用并给出原因。菜单 MUST 与画布菜单、元素菜单、参考线菜单互不混排。

#### Scenario: 顶部标尺只删垂直参考线

- **WHEN** 页面有 2 条垂直与 1 条水平参考线时右键顶部标尺并选择「删除所有垂直参考线」
- **THEN** 垂直参考线被清空，水平参考线保留

#### Scenario: 角落块清除全部

- **WHEN** 右键左上角块并选择「清除所有参考线」
- **THEN** 当前页面的所有参考线被清空

#### Scenario: 空方向禁用

- **WHEN** 页面没有垂直参考线时右键顶部标尺
- **THEN**「删除所有垂直参考线」呈禁用状态并提示当前页面没有参考线

### Requirement: 选中图层的区间高亮

画布存在选区时，标尺 SHOULD 用半透明色带标出选区在两条轴上的跨度，让用户能直接读出图层的位置与尺寸；色带 MUST 随缩放与平移同步，MUST NOT 拦截指针事件。

#### Scenario: 选中图层

- **WHEN** 选中一个位于世界 (80, 120)、尺寸 400×240 的图层
- **THEN** 顶部标尺在对应屏幕区间出现色带，左侧标尺同样出现色带

#### Scenario: 取消选中

- **WHEN** 取消选中所有图层
- **THEN** 两条标尺上的色带消失

### Requirement: 标尺快捷键

按 `⌃R`（Control-R）SHALL 切换「显示标尺」，与 Sketch 一致；该快捷键 MUST 在编辑器内阻止浏览器刷新，但 MUST NOT 抢占 `⌘/Ctrl+R` 之外的组合，也 MUST 在输入框、菜单或对话框中失效。

#### Scenario: 快捷键开关

- **WHEN** 在画布焦点下按 `⌃R`
- **THEN** 标尺显示 / 隐藏切换，浏览器不刷新页面

#### Scenario: 输入时不触发

- **WHEN** 焦点在文本输入框内按 `⌃R`
- **THEN** 不切换标尺
