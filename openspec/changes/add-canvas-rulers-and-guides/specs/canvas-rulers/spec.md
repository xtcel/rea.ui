## ADDED Requirements

### Requirement: 顶部与左侧标尺

开启「显示标尺」后，画布 SHALL 在顶部与左侧各显示一条 20px 厚的标尺，以及左上角 20×20 的角块。标尺 MUST 是固定在屏幕空间的覆盖层，不随设计内容缩放；标尺 MUST NOT 改变 `.rea-canvas` 容器的尺寸、位置或 `screenToWorld()` / `worldPoint()` 的坐标契约。关闭开关时两条标尺与角块 MUST 全部隐藏。

#### Scenario: 默认关闭

- **WHEN** 首次打开一个页面，偏好中没有任何显式设置
- **THEN** `showRulers` 为 false，画布不显示标尺与角块

#### Scenario: 手动开启显示

- **WHEN** 通过独立「视图」菜单开启「显示标尺」
- **THEN** 画布顶部与左侧各出现一条标尺，左上角为不带刻度的角块

#### Scenario: 关闭标尺不影响参考线

- **WHEN** 页面已有参考线，且 `showGuides` 为 true 时关闭「显示标尺」
- **THEN** 两条标尺与角块消失，参考线仍保持可见与可拖动，画布内容的位置和缩放比例不变

#### Scenario: 缩放不影响标尺厚度

- **WHEN** 画布缩放从 100% 变为 300%
- **THEN** 标尺仍为屏幕 20px 厚，刻度读数按新的 `zoom` 重新计算

### Requirement: 刻度读数与密度

标尺 SHALL 以「标尺原点」为 0 点、以设计 px 为单位显示刻度，原点默认为页面世界坐标 (0,0)；刻度位置 MUST 使用 `screen = world * zoom + camera.x|camera.y`，标签值 MUST 为 `world - origin`。系统 SHALL 从 1/2/5/10/20/50/100/200/500/1000/2000/5000 序列中选取满足 `step * zoom >= 8px` 的最小步长作为次刻度，主刻度步长为次刻度的 10 倍并显示数字标签；负坐标 MUST 带负号显示。刻度文字 MUST 使用固定 10px 屏幕字号（等宽数字），MUST NOT 使用 CSS `zoom`。改变原点 MUST 只改变标签读数，MUST NOT 改变任何参考线或图层的世界坐标。

#### Scenario: 100% 下的主刻度

- **WHEN** `zoom = 1`、`camera.x = 80`，页面世界原点在视口内
- **THEN** 顶部标尺在屏幕 x = 80、180、280… 处显示 `0`、`100`、`200`… 标签，中间有 10px 间隔的次刻度

#### Scenario: 平移后 0 点跟随

- **WHEN** 画布向右平移 40px
- **THEN** 世界 0 点的标签移动到屏幕 x = 120，其余刻度同步平移

#### Scenario: 负坐标

- **WHEN** 视口左侧对应世界 x = -150
- **THEN** 标尺在该区域显示 `-200`、`-100` 等带负号的读数

#### Scenario: 缩小到 10%

- **WHEN** 缩放为 10%
- **THEN** 次刻度步长自动放大，屏幕上的刻度间距不小于 8px，且标签数字仍是设计 px 值而非屏幕 px 值

#### Scenario: 放大到 300%

- **WHEN** 缩放为 300%
- **THEN** 次刻度步长自动缩小，标签不重叠且仍以设计 px 标注

### Requirement: 指针位置指示

指针在设计画布内移动时，两条标尺 SHOULD 在对应的屏幕坐标处显示位置指示（刻度三角形或短标记），数值为该点的世界坐标。指示更新 MUST NOT 触发整个 `Canvas` 组件重渲染；标尺覆盖层默认 MUST 为 `pointer-events: none`，仅标尺条带自身接收指针事件。

#### Scenario: 指针移动

- **WHEN** 指针在画布上从世界 (100, 50) 移到 (240, 50)
- **THEN** 顶部标尺的指示器随 `100 * zoom + camera.x` 变为 `240 * zoom + camera.x`，左侧标尺指示器保持不变

#### Scenario: 不遮挡画布点击

- **WHEN** 标尺开启，在标尺覆盖层之外单击一个图层
- **THEN** 该图层被正常选中，覆盖层不拦截命中测试

### Requirement: 标尺手势的分流与原点拖动

标尺上的指针手势 SHALL 按方向分流，与 Sketch 一致：移动距离小于 4px 视为**单击**，由上层创建垂直于该标尺的参考线；沿标尺轴向拖动 MUST 移动标尺原点；向画布方向拖动 MUST 创建参考线。原点被锁定时，沿轴拖动 MUST 无效果。顶部标尺的沿轴拖动为水平方向、左侧标尺为垂直方向；拖动标尺时 MUST 保证 0 点跟随指针（原点向反方向等量平移 `dx / zoom`）。拖拽进行中的标尺 MUST 有明确光标与无障碍名称，标尺上的 `pointerdown` MUST NOT 冒泡为画布的图层选择 / 框选手势。

#### Scenario: 单击与拖动的分流

- **WHEN** 在顶部标尺上原地按下松开
- **THEN** 创建一条垂直参考线，原点不变

#### Scenario: 沿轴拖动移动原点

- **WHEN** 在顶部标尺上按下并向右拖动 100px（缩放 50%）
- **THEN** 标尺原点在世界 x 方向减少 200，刻度标签整体右移，参考线与图层坐标不变

#### Scenario: 锁定原点

- **WHEN** 原点已锁定，沿顶部标尺拖动 100px
- **THEN** 原点与刻度标签均不变化，也不会创建参考线

#### Scenario: 重置原点

- **WHEN** 原点偏移后选择「重置标尺原点」，或双击左上角块
- **THEN** 原点回到 (0,0)，标签恢复为世界坐标读数

#### Scenario: 标尺关闭时没有拖出入口

- **WHEN** `showRulers` 为 false 时在画布左上角按下并拖动
- **THEN** 走普通画布手势，不会出现参考线预览

### Requirement: 标尺右键菜单

右键单击顶部标尺 SHALL 提供「删除所有垂直参考线」，右键单击左侧标尺 SHALL 提供「删除所有水平参考线」，右键单击左上角块 SHALL 提供「清除所有参考线」；三者 MUST 同时提供「显示标尺」「显示参考线」「锁定标尺原点」「重置标尺原点」。对应方向没有参考线时删除项 MUST 禁用并给出原因；原点锁定时「重置标尺原点」MUST 禁用。菜单 MUST 与画布菜单、元素菜单、参考线菜单互不混排。

#### Scenario: 顶部标尺只删垂直参考线

- **WHEN** 页面有 2 条垂直与 1 条水平参考线时右键顶部标尺并选择「删除所有垂直参考线」
- **THEN** 垂直参考线被清空，水平参考线保留

#### Scenario: 角落块清除全部

- **WHEN** 右键左上角块并选择「清除所有参考线」
- **THEN** 当前页面的所有参考线被清空

#### Scenario: 空方向禁用

- **WHEN** 页面没有垂直参考线时右键顶部标尺
- **THEN**「删除所有垂直参考线」呈禁用状态并提示当前页面没有参考线

### Requirement: 选中图层的区间高亮

画布存在选区时，标尺 SHOULD 用半透明色带标出选区在两条轴上的跨度，让用户能直接读出图层的位置与尺寸；色带 MUST 随缩放与平移同步，MUST NOT 拦截指针事件。

#### Scenario: 选中图层

- **WHEN** 选中一个位于世界 (80, 120)、尺寸 400×240 的图层
- **THEN** 顶部标尺在对应屏幕区间出现色带，左侧标尺同样出现色带

#### Scenario: 取消选中

- **WHEN** 取消选中所有图层
- **THEN** 两条标尺上的色带消失

### Requirement: 标尺快捷键

按 `⌃R`（Control-R）SHALL 切换「显示标尺」，与 Sketch 一致；该快捷键 MUST 在编辑器内阻止浏览器刷新，但 MUST NOT 抢占 `⌘/Ctrl+R` 之外的组合，也 MUST 在输入框、菜单或对话框中失效。

#### Scenario: 快捷键开关

- **WHEN** 在画布焦点下按 `⌃R`
- **THEN** 标尺显示 / 隐藏切换，浏览器不刷新页面

#### Scenario: 输入时不触发

- **WHEN** 焦点在文本输入框内按 `⌃R`
- **THEN** 不切换标尺
