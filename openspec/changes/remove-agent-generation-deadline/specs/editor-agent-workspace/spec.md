## ADDED Requirements

### Requirement: 生成任务不设总时长上限

系统 MUST NOT 因任务已运行超过固定时长而终止 Codex 生成或 API 流式生成。任务只能因用户停止、子进程退出、校验失败或连接确实中断（长时间没有任何新数据）而结束。运行期间 MUST 持续更新进度，使「仍在生成」与「卡死」可区分。

#### Scenario: 大需求超过十分钟仍在产出

- **WHEN** Codex 生成已运行超过 10 分钟，子进程仍在输出事件
- **THEN** 任务保持 `running`，不写入失败原因，也不终止子进程
- **AND** 连续一分钟没有新进度时，最后一条进度更新为「仍在生成 · 已用时 N 分钟」

#### Scenario: 用户主动停止长任务

- **WHEN** 已运行超过 10 分钟的任务被用户点击停止
- **THEN** 任务标记为 `cancelled` 并终止子进程，已同步的设计保留可编辑

#### Scenario: 流式响应连接中断

- **WHEN** API 提供商的流式响应读取报错
- **THEN** 任务以「连接中断（原因）」失败，而不是按总时长判定超时，也不落到「没有返回内容」

#### Scenario: 长回复不被总时长截断

- **WHEN** 流式响应持续有新数据但总时长超过 10 分钟
- **THEN** 读取继续，直到收到结束标记或用户停止
