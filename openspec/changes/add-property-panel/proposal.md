## Why

现有属性面板只覆盖名称、XYWH、单一颜色、圆角、文字内容与字号，与 Figma / Sketch 的「设计」面板相比字段不足、数值输入体验简陋（只能键入，不支持拖动调值、方向键步进、表达式、混合值）。这是 4 个阶段中的最后一个阶段（M4），依赖 `add-editing-core`（多选与批量事务），属性字段全部通过 `@rea/tailwind` 读写 className。

## What Changes

- 「设计」标签按 Figma 的顺序分区：对齐 → 画框 → 位置与尺寸 → 自动布局 → 图层 → 填充 → 描边 → 效果 → 文字。
- 每个字段对应 `@rea/tailwind` 中的一个属性组；写入遵循「刻度优先、否则任意值」。
- 数值输入框：左右拖动标签调值、↑/↓ 步进（`Shift` ×10）、支持表达式（`100+20`、`50%`）、多选时值不同显示 `Mixed`、`Enter` 提交 / `Esc` 还原。
- 颜色选择器：色板、十六进制与透明度输入、吸管（浏览器支持时）、最近使用的颜色。
- 多选时批量修改，一次操作一个历史项。
- 对齐与分布：6 种对齐、水平 / 垂直等间距分布。
- 画框预设尺寸、自动布局（方向、间距、内边距、对齐、宽高模式）。
- 描边（颜色、粗细、位置、虚线）、效果（投影、内阴影、图层模糊、背景模糊）。
- 文字：字体、字重、字号、行高、字间距、水平对齐、装饰线、大小写；文字尺寸模式切换。
- `className` 中无法被面板识别的类，在面板底部以「其他样式」只读列出。

## Capabilities

### New Capabilities
- `property-panel`: 「设计」标签的所有分区、字段、与 className 的映射、多选行为。
- `property-inputs`: 数值输入、颜色选择、下拉与分段控件的通用交互。
- `align-distribute`: 对齐与分布操作。

### Modified Capabilities
（无。新增的属性组遵循 M1 `tailwind-styling` 已有的读写、刻度优先与增量修补要求，不改变这些要求本身；具体映射见 `design.md` D2。）

## 范围说明（需要确认）

本阶段只做第一轮方案中优先级为 P0 与 P1 的字段。以下内容**不在本次范围**：

- **多个填充**与**渐变 / 图片填充**：Tailwind 的单个类无法稳定表达多个填充，本阶段每个节点只有一个纯色填充（带透明度、可显隐）；
- 混合模式；
- 导出面板（按倍率导出 PNG / SVG）；
- 文字的垂直对齐（需要额外的容器结构）；
- 自定义字体加载（字体字段只写入字体名，使用系统已有字体）。

## Impact

- `packages/editor`：重写 `Inspector`，新增 `inspector/` 目录下各分区组件；基于 M2 的 `ui/` 控件库增加 `NumberField`、`ColorField`、`Select`、`Segmented`。
- `packages/tailwind`：新增属性组与对应测试。
- `packages/document`：无新增操作，复用 `set` 与批量事务；对齐与分布产生批量 `set`。
- 用户的最近颜色保存在 localStorage。
