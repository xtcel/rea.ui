## ADDED Requirements

### Requirement: 对齐
「对齐」分区 SHALL 提供六个对齐操作：左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐。选中一个节点时 MUST 相对其父级对齐（页面上的游离图层没有父容器，单选时对齐按钮禁用）；选中多个节点时 MUST 相对这些节点的整体包围盒对齐。对齐只改变 `left-*` 或 `top-*`，MUST NOT 改变尺寸。一次对齐 SHALL 在一个事务中提交。

#### Scenario: 多选左对齐
- **WHEN** 选中 A（x=100）、B（x=140）并点击左对齐
- **THEN** A、B 的 x 都为 100，y 与尺寸不变

#### Scenario: 单个节点相对父级居中
- **WHEN** 选中宽 200 的矩形，其父画框宽 400，点击水平居中
- **THEN** 矩形 x 变为 100

#### Scenario: 一步撤销
- **WHEN** 对齐三个节点后撤销
- **THEN** 三个节点的位置同时恢复

#### Scenario: 游离图层单选时禁用
- **WHEN** 选中一个页面上的游离图层（只选中它一个）
- **THEN** 对齐按钮禁用

### Requirement: 分布
选中至少 3 个节点时，系统 SHALL 提供水平等间距与垂直等间距分布：以最靠边的两个节点为界，按当前位置排序，使相邻节点之间的间隙相等。分布只改变位置，MUST NOT 改变尺寸。选中不足 3 个节点时 MUST 禁用分布按钮。

#### Scenario: 水平等间距
- **WHEN** 选中位置 x 为 0、30、200，宽均为 50 的三个节点，点击水平等间距
- **THEN** 中间节点的 x 变为 100（两侧间隙相等，均为 50）

#### Scenario: 少于三个
- **WHEN** 选中两个节点
- **THEN** 分布按钮禁用

### Requirement: 对齐与分布的适用范围
对齐与分布 MUST 只作用于自由定位（含 `absolute`）的节点。选中的节点中含有流式节点时，对齐与分布按钮 MUST 禁用，并在悬停时说明原因（位置由容器布局决定）。被锁定的节点 MUST NOT 被移动，并被跳过且提示。

#### Scenario: 含有流式节点
- **WHEN** 选中的节点中有一个在自动布局容器内
- **THEN** 对齐与分布按钮禁用，悬停提示说明原因

#### Scenario: 跳过锁定节点
- **WHEN** 选中的节点中有一个被锁定
- **THEN** 其他节点正常对齐，锁定的节点保持不变，并提示有节点被跳过

### Requirement: 键盘快捷键
对齐 SHALL 提供与常见设计工具一致的快捷键：`Alt + A` 左对齐、`Alt + D` 右对齐、`Alt + W` 顶对齐、`Alt + S` 底对齐、`Alt + H` 水平居中、`Alt + V` 垂直居中。快捷键 MUST 在焦点位于输入框时不生效。

#### Scenario: 快捷键左对齐
- **WHEN** 选中两个节点，焦点在画布上，按 `Alt + A`
- **THEN** 两个节点左对齐

#### Scenario: 输入框中不触发
- **WHEN** 焦点在输入框内按 `Alt + A`
- **THEN** 不执行对齐
