# 基础可编辑版本验证记录

日期：2026-11-02。本记录取代此前只读框架的验证范围。

## 自动检查

- `pnpm build`：Cargo 编译 WASM、TypeScript 检查、Vite 生产构建通过。
- `pnpm test`：5 个文件、19 项测试通过，包括加载真实编译 WASM 的集成测试。
- `pnpm test:rust`：4 项 Rust 几何测试通过。

测试覆盖身份/层级、重复身份拒绝、非法源码拒绝、锁定/隐藏继承、局部源码修改保留原文、失败原子性、文本内容与空格、精确源码撤销重做、历史分支、SVG 渲染、相机，以及 Rust/WASM 的绘制归一化、吸附和缩放边界。

## 浏览器实测

在 Codex 内置浏览器验证：

- 工具栏实际绘制矩形；新增对象立即进入图层树与源码。
- 拖动矩形改变源坐标；手柄缩放改变尺寸；一次缩放可用一次 Undo 恢复，Redo 可重新应用。
- F 工具拖动新增独立画板，左侧可切换，宽高可在属性面板修改。
- 新画板中继续创建矩形、椭圆、文本。
- 删除椭圆后 Undo 恢复。
- 修改文本为中文，当前 TSX 源码包含相同内容。
- 修改十六进制填充颜色，DOM 实际计算颜色与提交值一致。
- “导出 TSX”实际生成 `workspace.design.tsx` 下载文件。
- 浏览器重载后设计内容恢复；撤销栈按当前实现重新开始。
- 390px 窄屏属性面板可用，页面无横向溢出。

Rust Clippy（`-D warnings`）和界面静态检查通过。桌面截图已更新为可编辑版本。

本轮独立画板通过列表切换，尚未实现把多个独立画板在同一无限画布自由排布。当前是基础设计编辑能力，不能视为专业矢量、组件、完整布局或大文档性能验收。
