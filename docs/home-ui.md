# 首页工作空间

首页是在既有 REA UI 视觉系统内增加的入口，沿用 `theme.css` 的白灰表面、蓝色状态、系统字体与 Lucide 轮廓图标，不替换编辑器设计系统。

## 已实现界面

- 桌面为导航栏与内容区两列，导航按「首页 / 全部项目 / 设计系统 / 模板 / 设置 / 最近项目」排列。最近项目默认展开，侧栏最多显示 5 项；首页显示最近 2 项和新建入口。设置不再占用内容区，点击后打开独立的设置窗口（多窗口或弹出窗口，被拦截时回退为整页）；详见 [设置说明](settings.md)。
- 首页包含设计需求输入框、附件添加与移除、设计系统选择、工作目录选择、模型选择和发送按钮。支持 Enter 或 ⌘ / Ctrl + Enter 发送，Shift + Enter 换行；切换页面保留当前会话中的草稿。
- 全部项目与设计系统分别提供搜索、排序、网格 / 列表切换和新建入口；无搜索结果时可以清除搜索恢复列表。模板卡片会返回首页并填入需求。
- 桌面导航宽 228px，内容顶栏高 64px，输入区最大宽 760px。小于 1150px 时导航收窄、网格改为两列；不超过 760px 时导航转为模态抽屉，工具栏换行；小于 540px 时网格为单列。
- 交互状态保留可见键盘焦点、图标按钮名称、当前导航与视图状态；提供跳转内容链接、加载 / 错误 / 空状态，并遵循减少动态效果偏好。

## 本地项目集成

`apps/web/src/main.tsx` 在几何内核初始化后挂载 `HomeApp`，并加载 `home.css`。首页通过现有 `useDocument` 与 `StorageService` 读取 IndexedDB 文档摘要；打开和新建操作使用现有文档模型，进入共享的 `EditorWorkspace`。编辑器的「返回首页」入口复用同一模型，保留原有保存、导入与导出能力。

项目名称和更新时间来自真实本地文档。最近访问记录、项目与系统各自的视图、Agent / 发送快捷键 / 项目路径偏好以及自定义设计系统保存在 `rea-home:*` localStorage 中。最近访问记录最多保留 20 个 ID；首页导航、草稿、附件、对话属于当前会话；当前系统选择持久化保存。

## 本地 Agent 与设计系统

首页 AI 输入框按用户参考图调整为白色圆角输入区和灰色工作目录栏：左侧为圆形加号与设计系统选择，右侧为真实连接状态、提供商设置入口和黑底绿色发送箭头。多行输入自动增高，空内容禁用发送；生成中显示停止按钮。连接状态跟随「设置 → 模型与提供商」中的当前选择：本地 CLI 读取 `--version` 与登录状态，API 提供商只检查地址、模型与密钥是否齐全。

加号菜单提供「附加文件 / 引用其他项目 / 关联本地代码」；引用项目从本地设计库只读读取，与附件合计最多 6 项。插件、Figma 导入、连接器与 MCP 显示为「暂未接入」。菜单支持方向键、Esc、点击外部关闭，并根据视口自动调整位置。输入区的圆角和发送配色是本次参考图指定的局部样式，其他工作台控件继续沿用既有设计系统。

首页已接通 Codex CLI。输入需求后显示真实阶段，支持取消和错误重试；生成内容通过静态校验后保存为新文档并打开编辑器。关联本地项目保存真实路径并读取代码参考；附件支持 `.reaui` 与文本资料。配置、设计系统、默认选择和项目关联保存在本地；对话、草稿和附件属于当前会话。

设计系统的创建与详情已改为独立全屏页面（见下节），不再占内容区；内置系统修改后保存为副本。现有项目封面仍是示意图，不是文档截图。完整功能和边界见 [本地 AI 生成说明](local-agent.md)。

## 设计系统页

设计系统的「新建」和「详情」是同一个独立页面，参考 Claude Design 的「左侧对话、右侧画布」：对话是作者面，右侧是系统本身。

- **创建以对话为主。** 新建入口打开的是空白会话，不是预填令牌的表单。左侧提供三种来源：「用描述生成」「从本地项目提取」（选目录后直接读取令牌与组件样式）、「导入 DESIGN.md / CSS / tokens.json」（选中的文件挂到输入框并预填提取指令，由用户确认后发送，入口处不校验 frontmatter）；下方给出可一键发送的起点（SaaS 工具 / 品牌官网 / 数据看板 / 移动应用）。已保存的系统改为显示「常用调整」（检查对比度、补齐交互状态、扩展排版阶梯、补充组件规则）。
- **右侧是规范页，不是表单。** 顶部没有标签栏：右侧再分「目录 + 内容」两列，目录列出概览 / 配色 / 排版 / 间距 / 圆角 / 动效 / 组件 / 指南 / 版本，点击即锚点跳转，滚动时按区块位置自动高亮当前项（判定线在面板顶部约 10%，到底部时锁定最后一节）。目录顶部有令牌搜索：命中时只保留命中的区块、标出命中的行，并在跳转时落到第一个命中项。
- **就地编辑，控件即字段。** 概览先渲染实时样本（用系统自身的 `--ds-*` 令牌），再给出介绍；其余区块按令牌分组展开，色块、hex、字号、行高、字重、基数、圆角与动效档位都可直接改。「刚刚更新 N 项」显示在目录里，命中的区块标题转为强调色。
- **每轮生成都是一次完整快照。** Agent 按 `systemSchema` 返回整套系统（含一句 `summary`），页面替换草稿并自动保存到 `rea-home:systems`，同时在右侧标出被改动的行与「刚刚更新 N 项」；对话里保留执行过程与「本轮改动」清单。
- **保存与发布分离。** 本地编辑防抖 700ms 自动保存，顶栏状态显示 `草稿 / vN / 已启用`；「发布版本」写入 `design-system-versions`，「用于 UI 生成」把系统标记为可用。内置系统只读，首次编辑或发布自动派生「… 副本」。
- **尺寸与降级。** 顶栏 52px，对话栏 388px（≤1180px 为 344px），右侧目录 184px（≤1180px 为 168px）。≤940px 上下堆叠，对话占 50% 高度；≤760px 目录折叠成内容上方的横向胶囊条（隐藏搜索，计数省略）；≤620px 收窄标题与正文，隐藏顶栏的「用于 UI 生成」。对话位于首屏时不自动滚动，出现首轮内容后才跟随到底部。
- **状态。** 空白系统在右侧给出「这套系统还没有内容」与将要生成的五项结构，并提供导入 / 关联项目的快捷入口；发布、生成、导入的失败与成功都在顶栏下方给出可关闭的提示条。
