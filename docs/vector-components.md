# 矢量工具与组件使用、验收记录

对应 OpenSpec `add-vector-tools-and-component-libraries`，2026-11-03。

## 直接体验

导入 [功能示例](../examples/vector-components.reaui)。可编辑源文件位于 [examples/vector-components](../examples/vector-components/)。示例包含线条、箭头、三角形、星形、多边形、贝塞尔路径，以及两个关联卡片实例；第二个实例替换图标并填充独立插槽。

- 形状菜单选择新增形状；Shift 约束方向/比例，Alt 从中心绘制。右侧可以调整边数、角数、内半径和首尾箭头。
- P 钢笔，点击直线、拖出控制柄绘制曲线，点击首点闭合，Enter 结束。Shift+P 铅笔，释放后平滑为路径。双击路径编辑锚点；支持尖角/平滑/对称、增删锚点与开放路径续画。
- 选中普通图层，点击“创建组件”；资源面板插入关联实例。通过“查看主组件”编辑定义，通过“返回页面”退出。实例面板提供属性、变体、重置、切换和分离。
- 主组件中选中图层后可暴露属性，选中容器可创建插槽；实例只能在插槽内增删/重排自有内容。
- 资源面板发布本地库，在另一文档的“组件来源”选择库后插入。源文件编辑不影响固定版本；发布新版本后使用方先预览差异，再“接受更新”。冲突会阻止升级；升级支持撤销。

## 范围与限制

本次没有布尔运算、分支矢量网络或团队云协作。旧 SVG d 继续渲染，圆弧/多轮廓暂不转换为锚点。位图清晰度受原图像素限制。组件库发布历史保存在本机；单个 .reaui 携带其使用的定义/资源快照。跨文档复制遇到同一组件身份内容分叉时明确拒绝，需要先更新库或分离后复制。

没有逐一人工覆盖所有旋转、吸附、IME、设备 DPR 与工具组合；这些基础行为有现有回归，以上记录区分了本次实际操作范围。
